- 🎓 Creator and lead developer of **EduCraft**, an educational platform with a browser client, multi-center backend and managed Minecraft infrastructure.
- 🧠 Building **PCB-Vibe**, an AI-assisted PCB prototyping project.
- 🖥️ Into **Linux, servers, networking, backend architecture, homelabs and infrastructure**.
