## 🚀 Main project

### 🎓 [EduCraft](https://github.com/enzogarcia90/EduCraft)

A platform designed for educational centers, with a browser client and an infrastructure that connects schools, classes and game servers through a managed backend.

**Some of the stack:**

`Go backend` · `PostgreSQL` · `Redis` · `JWT` · `Velocity` · `Paper` · `WebAssembly` · `Stripe` · `Linux` · `Caddy`

Current focus includes multi-center architecture, classroom server orchestration, dashboards, billing, security systems and game/backend integration.
